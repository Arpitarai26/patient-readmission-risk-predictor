# Patient Readmission Risk Predictor

## Project Overview

Predict whether a diabetic patient will be readmitted within 30 days after hospital discharge.

## Business Problem

Hospital readmissions are expensive and may indicate inadequate post-discharge care.

Early identification of high-risk patients allows healthcare providers to intervene before readmission occurs.

## Objective

Target Variable:

readmitted

Encoding:

- <30 = 1
- >30 = 0
- NO = 0

## Dataset

Diabetes 130-US Hospitals Dataset

Records: 101,766

Features: 50
